# Game UI art icons

Transparent, object-focused inventory-style art for the high-visibility reward and Pet Gauntlet stat surfaces. The set shares the game's shinobi-fantasy materials: deep indigo wraps, aged gold fittings, worn ivory/wood, restrained cinnabar, and directional warm light. Exported to 256 px WebP under `public/ui/game-icons/`.

## Creative briefs

- `vitality`: a red lacquered shinobi medicine gourd with a glowing vermilion seal, indigo tassel, and aged gold fittings; single centered object, no background, UI frame, lettering, or watermark.
- `speed`: a single worn indigo shinobi sandal with antique-gold fittings and a pale cyan wind trail; single centered object, no background, UI frame, lettering, or watermark.
- `bone-charm`: a single carved ivory bone talisman bound in indigo cord, antique-gold caps, and an ornate wind-knot carving; warm directional light, centered on transparency, no background, UI frame, lettering, or watermark.

Source PNGs are preserved beside this README. The art reuses the existing battle, guard, scroll, and donation objects from `public/ui/clan-missions/` where those subjects match; Fate Shard reuses the existing game item artwork.
