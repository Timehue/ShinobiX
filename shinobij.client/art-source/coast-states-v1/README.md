# Unmapped Coast state paintings
Sixteen original PNG masters supply the six atlas markers, eight plot standees and two scenes. The manifest records the ImageGen prompt and shipped filename for each master.

Run `node export.cjs` here to rebuild the local review delivery in `output/coast/coast-states-v1`. Supply a destination directory to export the same relative paths elsewhere. Magenta is removed from the cutout masters before conversion to transparent WebP. The scenes use the full 800 × 450 frame.

The dormant gate is one reusable boarded-door painting for all three tiers. Staked or fallen ground, construction, works and contest markers follow the server status. The Watch Fire goes dark during dormancy.
