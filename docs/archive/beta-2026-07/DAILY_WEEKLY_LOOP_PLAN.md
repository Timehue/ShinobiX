# Daily And Weekly Loop Plan

Date: July 7, 2026

## Goal

Give beta players a repeatable reason to return without turning the first week into a chore list. The daily loop should point players back to core progression; the weekly loop should create goals for players who stay longer.

## Daily Loop

| Loop | Target player | Current state | Beta call |
| --- | --- | --- | --- |
| Academy/Logbook next step | New players | Existing Academy path and Logbook goals | Primary first-session loop. |
| Newbie daily missions | Pre-profession players | Two daily ryo tasks, 120/160 ryo rewards | Keep; monitor completion. |
| Profession daily missions | Level 13+ | Healer, Vanguard, Pet Tamer mission pools | Keep; monitor profession balance. |
| Missions and hunts | All players | 20 mission and 20 hunt caps per day | Keep; core repeatable loop. |
| Training | All players | 15m/1h/4h/8h tiers | Keep; primary stat growth. |
| Bank interest | Players with deposits/upgrades | Claim once per 24h | Keep; monitor inflation. |
| Village agenda | Village-engaged players | Exists in village state | Monitor; do not force on new players. |
| Hospital recovery | KO players | Wait timer or paid discharge | Watch for soft-lock reports. |

## Weekly Loop

| Loop | Current state | Beta call |
| --- | --- | --- |
| Weekly board | Existing weekly board and claim path | Good beta retention loop after fresh-account smoke. |
| Battle Towers/Endless Tower | Existing advanced PvE | Promote as monitored advanced content after mobile smoke. |
| Pet Arena/Ladder | Existing side progression | Soft-launch and monitor queue/stuck reports. |
| Weekly Boss | Scheduled system, client damage gated | Keep rewards/contribution gated until server-authoritative settlement. |
| Village/Sector War | Built but high-impact | Staffed soft launch only. |
| Created content showcases | Possible through admin/review | Invite-only or staff-curated only. |

## First Week Player Flow

1. Day 0: Create character, finish Academy Training, claim first mission, open Logbook.
2. Day 1: Use Logbook/Daily Briefing, complete missions/hunts, start longer training.
3. Day 2-3: Reach profession choice, try profession daily loop, explore pets/clan gently.
4. Day 4-7: Try PvP, towers, weekly board, and midgame missions if interested.

## Beta Patch 1 Content Shape

Safe additions:

- More clear daily/weekly copy.
- Better reward summaries.
- Empty states for low-population tasks.
- One or two small mission/story flavor additions with existing reward tables.

Avoid:

- New currencies.
- New reward tables.
- Broad war-season launch.
- Public creator economy.
- Any weekly boss contribution payout without server authority.

## Metrics

- Daily active characters.
- Newbie daily completion count.
- Profession daily completion by profession.
- Mission/hunt claims by level band.
- Training sessions started and claimed.
- Weekly board claims.
- Tower runs started/completed.
- PvP sessions settled.
