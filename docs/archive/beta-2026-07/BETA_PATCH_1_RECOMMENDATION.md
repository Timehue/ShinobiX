# Beta Patch 1 Recommendation

Date: July 7, 2026

## Recommendation

Ship Beta Patch 1 as a conservative clarity, monitoring, and runbook patch. Do not change combat, XP, economy, training, profession, or village balance numbers before the first beta cohort produces data.

## What This Patch Changes

- Adds beta feedback triage.
- Adds beta metrics checklist.
- Adds level 1-10, level 10-50, and level 50-100 progression audits.
- Adds PvP and PvE beta balance audits.
- Adds economy, village, created content, reward presentation, daily/weekly loop, content plan, notes draft, and final recommendation docs.

## Balance And Economy Values Changed

None.

No AP costs, damage formulas, cooldowns, XP curve values, ryo rewards, training rates, profession thresholds, village values, bank interest, hospital costs, or mission rewards were changed in this patch.

## Top 5 Fixes For Beta Patch 1

1. Run live/staging fresh-account smoke through first mission claim.
2. Add or confirm aggregate beta metrics for Academy completion, first mission claim, reward claims, PvP settlement, level distribution, and ryo distribution.
3. Verify mobile core gameplay screens before promoting beta broadly.
4. Keep high-risk reward systems gated unless staff can inspect receipts and respond quickly.
5. Publish clear patch notes that label monitored/gated systems.

## Safe To Enable Or Promote

- Core onboarding, Training, Missions, Inventory, Bank, Hospital, Shop.
- Early missions and hunts.
- Logbook and Daily Briefing.
- PvP/Ranked with monitoring and receipt review.
- Battle Towers/Endless Tower after mobile smoke.
- Pet Arena/Pet Ladder as monitored side systems.
- Profession dailies after level 13.

## Keep Gated, Staffed, Or Desktop-First

- Weekly Boss contribution rewards until server-authoritative settlement is enabled.
- High-tier client-trusted combat mission rewards.
- Broad Village/Sector War seasons.
- Hollow Gate mobile promotion.
- Bloodline Maker public promotion.
- Player AI image generation.
- Unreviewed created combat/economy content.

## Top Retention Risks

| Risk | Severity | Response |
| --- | --- | --- |
| Fresh-account save or first mission failure | P1/P0 depending on data loss | Smoke and patch immediately. |
| Players lose direction after Academy | P2 | Use Logbook/Daily Briefing/copy, not reward inflation. |
| Level 13 profession choice confusion | P2 | Track choice rates and add clearer empty states. |
| Level holds feel like bugs | P2 | Reinforce exam copy before level 20/39. |
| Mobile combat controls block play | P1/P2 | Patch layout before balance. |

## Top Balance Risks

| Risk | Severity | Response |
| --- | --- | --- |
| PvP burst/stun complaints | P2 unless exploit | Inspect receipts and match length first. |
| War/boss reward inflation | P0/P1 if enabled broadly | Keep gated/staffed. |
| Early ryo poverty after KO | P2/P1 if soft-lock | Add targeted fallback only with evidence. |
| Profession imbalance | P2 | Wait for usage and completion data. |
| Village population skew | P2 | Improve presentation, not power, unless data proves a mechanical problem. |

## Exact Next Steps

1. Run the requested validation commands.
2. If validation passes, commit the docs-only patch.
3. Push to the requested destination only after validation.
4. Before inviting players, run live/staging browser smoke with a new account.
5. After first beta day, publish a one-page metrics and P0/P1 report.

## Launch Statement

Beta Patch 1 can support a controlled public beta. It should not be described as final balance, final endgame, or a full competitive launch.
