# Copy, Labels, And Player Trust Release Audit

Date: July 7, 2026

## Verdict

The game has enough instructional copy for beta, and this pass improved the most immediate trust gaps. The largest remaining copy issue is brand consistency: repository/handoff language says ShinobiX, while much of the player-facing landing uses Shinobi Journey.

## Fixes Implemented

- Added clear public-beta notices for systems that are gated, monitored, or desktop-first.
- Rewrote one-time screen hints into plain explanatory text.
- Added player-facing explanation when AI image generation is disabled during public beta.
- Avoided claiming Weekly Boss, war, Hollow Gate, creator tools, or AI generation are fully public-ready.

## Copy Risks

| Risk | Status | Recommendation |
| --- | --- | --- |
| ShinobiX vs Shinobi Journey | Open | Decide final public brand and update landing/logos/docs consistently. |
| Dense system names | Improved | Hints now explain major menus on first open. |
| Rare currency meaning | Open | Add glossary/tooltips after beta feedback. |
| Beta systems sounding complete | Improved | Notices label gated/monitored/desktop-first systems. |
| Technical admin/dev language | Monitor | Admin screens can stay operational; player screens should avoid raw errors. |

## Terms To Standardize

- Public brand: choose `ShinobiX` or `Shinobi Journey`.
- `ryo`: use consistently in lowercase for currency.
- `Fate Shards`, `Honor Seals`, `Bone Charms`, `Aura Stones`, `Mythic Seals`: capitalize consistently and explain first use.
- `Public beta`, `soft-launch`, `desktop-first`: use for unfinished or monitored systems instead of implying full launch.
